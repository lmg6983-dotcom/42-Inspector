# 42-Inspector

특허 명세서 기재불비 검사기 (CLI). [기재굴비](https://leemocker.appspot.com/)의 검사 항목을 Rust로 옮기고 몇 가지를 보탰다.

```bash
cargo run --release -- 명세서.txt
```

파일을 주지 않으면 표준 입력에서 읽는다(UTF-8). 지적 사항이 있으면 종료 코드 1.
KIPO 전자출원 형식(`【청구항 1】`, `【도면의 간단한 설명】`, `【도 1】` …)의 머리말로 섹션을 나눈다. `[청구항 1]`처럼 대괄호여도 된다.

| 검사 | 내용 |
|---|---|
| 상기 체크 | `상기 X`의 X가 같은 청구항 앞부분이나 인용항(연쇄 인용 포함)에 나왔는지. 띄어쓰기 차이는 무시 |
| 부재번호 체크 | `이름(부호)` 목록. 한 부호에 여러 이름, 한 이름에 여러 부호를 지적 |
| 반복 단어 | `투명 투명`처럼 1~3어절이 바로 반복 |
| 괄호 뒤 조사 | `전극(20)는` → `전극(20)은`. 은/는 · 이/가 · 을/를 · 과/와 · (으)로 |
| 도면 체크 | 도면의 간단한 설명 ↔ 본문 ↔ 첨부 도면의 도면 번호. `도 3 내지 도 5`, `도 4a 내지 4c`, `도 5(a)` 지원 |
| 인용항 체크 | 없는/뒤 청구항 인용, 번호 누락, 택일적 기재(시행령 제5조 제5항), 다중→다중 인용(같은 조 제6항) |

예시: `cargo run -- examples/sample.txt`. 결과는 참고용이다.
